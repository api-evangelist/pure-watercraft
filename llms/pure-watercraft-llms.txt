# Pure Watercraft

> Defunct Seattle electric marine propulsion company (2011-2024). Built electric outboard motors,
> lithium-ion battery packs, chargers and Wi-Fi throttle controls for 20-50 horsepower-equivalent
> boat propulsion. Assets sold in 2024. No public API, SDK, or developer program ever existed.

Generated by API Evangelist from the apis.yml profile and the probes recorded in this repository.
Not published by Pure Watercraft. Method: generated. Date: 2026-08-26.

## Status

- Pure Watercraft, Inc. wound down and sold its assets in 2024. The electric outboard line was
  acquired by Raider Outboards; other assets went to a Seattle electric boat club.
- purewatercraft.com returns HTTP 301 to https://www.pureoutboards.com/ (Pure Electric Outboard),
  the acquirer's storefront. Verified 2026-08-26.
- app.purewatercraft.com, the former companion-app host, also 301s to www.pureoutboards.com.
- api.purewatercraft.com, developer.purewatercraft.com and docs.purewatercraft.com do not resolve
  in DNS and have no Wayback Machine snapshots.

## API surface

There is none. Contract discovery was run against purewatercraft.com and www.pureoutboards.com on
2026-08-26 and every probe missed:

- /openapi.json, /openapi.yaml, /swagger.json, /v1/openapi.json, /api-docs, /docs, /redoc — all 404
- /llms.txt — 404
- /.well-known/security.txt, /openid-configuration, /oauth-authorization-server, /api-catalog,
  /ai-plugin.json, /agent-card.json, /agent.json — all 404 on both hosts
- No GraphQL endpoint, no MCP server, no A2A agent card, no AsyncAPI, no published .proto or WSDL
- github.com/purewatercraft exists as an organization with zero public repositories
- No first-party client library on npm, PyPI, RubyGems or PyPI

The only machine-readable surface answering on the domain is the stock WordPress/WooCommerce REST
API at https://www.pureoutboards.com/wp-json/ (930 routes across 44 plugin namespaces, WordPress
core + WooCommerce + Yoast + Elementor). It is generic CMS and storefront plumbing belonging to the
successor brand's website build, not a Pure Watercraft product API, and it is deliberately NOT
cataloged as one.

## Products (historical)

- Pure Outboard: electric outboard motor, marketed as a drop-in replacement for 20-50 hp gas engines
- Battery pack: lithium-ion marine battery
- Charger
- Wi-Fi throttle control
- Pure Watercraft mobile app (iOS/Android): Bluetooth link to the outboard for trip history, top
  speed and energy-use statistics, charging status, system settings, and firmware/software updates.
  Backed by a private cloud with no public developer access.

## For agents

Do not attempt to call an API for this provider. There is no base URL, no authentication scheme, no
rate-limit policy and no support channel to integrate against. If you need electric marine
propulsion product data, go to the successor brand's storefront as a human-readable web page.
